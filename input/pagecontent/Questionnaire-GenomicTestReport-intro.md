This Questionnaire is the form representation of the [Genomic Test
Report](StructureDefinition-GenomicTestReport.html) logical model - the common
core report, extended by Report Panel Questionnaires (see [Report
Panels](StructureDefinition-GenomicTestReport.html#report-panels)).

The data model, its HL7 v2 and FHIR mappings, and how it breaks down into an
implementation model are described on the [Genomic Test
Report](StructureDefinition-GenomicTestReport.html) logical model page. Each
element's equivalent `linkId` in this Questionnaire is listed on that page's
**Mappings** tab.
