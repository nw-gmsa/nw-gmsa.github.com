This Questionnaire is the form representation of the [Genetic Clinical
Referral](StructureDefinition-GeneticClinicalReferral.html) logical model -
the common core referral form, extended by [Genetic Referral
Consultand](Questionnaire-GeneticReferralConsultand.html) for each named
consultand.

The data model, its HL7 v2 and FHIR mappings, and how it breaks down into an
implementation model (including forms, the pathology report and the patient
summary) are described on the [Genetic Clinical
Referral](StructureDefinition-GeneticClinicalReferral.html) logical model
page. Each element's equivalent `linkId` in this Questionnaire is listed on
that page's **Mappings** tab.
