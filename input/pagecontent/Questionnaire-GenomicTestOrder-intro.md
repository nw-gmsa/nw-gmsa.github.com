This Questionnaire is the form representation of the [Genomic Test
Order](StructureDefinition-GenomicTestOrder.html) logical model - the common
core order form, extended by Ask At Order Entry Questionnaires (see [Order
Entry Questions](StructureDefinition-GenomicTestOrder.html#order-entry-questions)).

The data model, its HL7 v2 and FHIR mappings, and how it breaks down into an
implementation model are described on the [Genomic Test
Order](StructureDefinition-GenomicTestOrder.html) logical model page. Each
element's equivalent `linkId` in this Questionnaire is listed on that page's
**Mappings** tab.
